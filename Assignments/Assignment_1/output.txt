TASK 12.A - Impact analysis
  event traffic         = 25,000 x 0.05 = 1250 Erl
  event traffic density = 1250 / 1 km^2 = 1250 Erl/km^2
  normal traffic        = 20,000 x 0.025 = 500 Erl ; density = 500 / 12 = 41.67 Erl/km^2
  ratio event/normal density = 30.0 (about 30x)
  event time share = 8 h per month of ~730 h = 1.1 %

TASK 12.B - Original design under the event (assumptions stated)
  assumption: stadium zone (1 km^2) is served by ceil(1/0.6495) = 2 original cells, 48 channels each, traffic split equally
  offered per cell = 625.0 Erl -> Erlang-B blocking = 0.9233 ; carried traffic = 95.8 of 1250 Erl (7.7 %)
  event cannot be carried by the entire licensed pool in one cell: channels for 1,250 Erl at 2 % = 1255  (> 336 available)
  event traffic (1250 Erl) > whole-township baseline capacity (729.4 Erl)
